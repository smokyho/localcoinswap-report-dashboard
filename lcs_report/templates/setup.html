How to fix

1 Create an API key at Preferences → API. An authenticator code is required.
2 Copy the secret. It looks like lcs_a1b2c3d4_your_secret and is shown only once. Write it to a .env file in the project root: 
echo "LCS_API_KEY=lcs_a1b2c3d4_your_secret" > .env
echo "LCS_USERNAME=your_lcs_username" >> .env
3 LCS_USERNAME lets the report tell a buy from a sell. It is auto-detected when omitted, but setting it removes the guesswork.
4 Restart the server, then reload this page.
